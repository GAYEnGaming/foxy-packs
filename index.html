📥 Installation Guide

How to install Foxy Shaders

  1. Download the shader ZIP file.
  2. Install Minecraft Java Edition.
  3. Install Iris Shaders and Sodium if required.
  4. Open Minecraft and go to Video Settings.
  5. Open the Shader Packs menu.
  6. Click Open Shader Pack Folder.
  7. Move the downloaded ZIP into the shaderpacks folder.
  8. Select Foxy Shader and enjoy!

How to install FOX SML Texture Pack

  1. Download the FOX SML ZIP file.
  2. Open Minecraft Options.
  3. Go to Resource Packs.
  4. Click Open Pack Folder.
  5. Move the ZIP file into the resourcepacks folder.
  6. Activate FOX SML.
