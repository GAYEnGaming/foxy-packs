📥 Installation Guide

How to install shaders

  1. Download your preferred Foxy shader ZIP.
  2. Install Iris Shaders and Sodium for compatible Minecraft Java versions.
  3. Open Minecraft and go to Options → Video Settings → Shader Packs.
  4. Open the shader pack folder.
  5. Place the downloaded ZIP inside the folder.
  6. Select the shader and enjoy!

How to install texture packs

  1. Download the texture pack ZIP.
  2. Open Minecraft → Options → Resource Packs.
  3. Click Open Pack Folder.
  4. Place the ZIP inside the folder.
  5. Enable the texture pack.
